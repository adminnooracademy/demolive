FIX HASIL ADMIN REALTIME

Masalah:
Peserta sudah mengerjakan/submit, tetapi hasil belum muncul di dashboard admin untuk dilihat/diolah.

Penyebab paling mungkin:
Submit ujian tersimpan di localStorage peserta, tetapi belum terdorong ke Firebase results dengan stabil.
Akibatnya admin hanya melihat status peserta, bukan tabel hasil realtime.

Yang diperbaiki:
1. Setelah peserta submit, sistem membaca hasil terakhir dari localStorage.
2. Hasil tersebut dikirim ke Firebase pada path results.
3. Dashboard admin menampilkan tabel baru: "Hasil Submit Realtime".
4. Tombol Export Hasil Realtime mengambil data dari Firebase dan fallback local.
5. Tombol Refresh Monitor reload peserta dan hasil dari Firebase.

File yang perlu diupload:
- realtime-monitor.js
- index.html
- styles.css

JANGAN ganti config.js.

Cara pakai:
1. Extract ZIP.
2. Upload 3 file di atas ke GitHub.
3. Commit changes.
4. Buka admin dan tekan Ctrl + F5.
5. Peserta login, mulai ujian, lalu submit.
6. Di dashboard admin klik Refresh Monitor.
7. Lihat bagian "Hasil Submit Realtime".

Kalau hasil masih belum muncul:
1. Buka Firebase Console > Realtime Database > Data.
2. Cek apakah ada:
   pmbRooms / pmb-stipi-2026 / results
3. Buka Console admin, ketik:
   PMB_REALTIME_DEBUG()
4. Kirim screenshot hasilnya.
