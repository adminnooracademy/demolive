FITUR BARU
1. Kamera wajib aktif sebelum peserta mulai ujian.
2. Preview kamera tampil di pojok kanan bawah.
3. Admin bisa pantau:
   - jumlah peserta aktif,
   - jumlah peserta on-camera,
   - jumlah peserta sedang ujian,
   - jumlah peserta selesai,
   - peserta yang kamera off saat ujian,
   - progress jawaban,
   - sisa waktu,
   - jumlah keluar tab/lost focus.
4. Hasil submit juga dikirim ke Firebase.
5. Admin bisa export status realtime dan hasil realtime ke CSV.

CARA UPLOAD
1. Extract ZIP.
2. Upload semua isi folder ke GitHub repository.
3. Pastikan index.html ada di root repo.
4. Commit changes.
5. Buka GitHub Pages.

PENTING
Web bisa tampil tanpa Firebase.
Namun fitur realtime admin baru aktif setelah config Firebase diisi.

CARA SETUP FIREBASE
1. Buka Firebase Console.
2. Create project.
3. Add app > Web.
4. Copy firebaseConfig.
5. Buka config.js.
6. Tempel firebaseConfig ke bagian firebaseConfig.
7. Buka Authentication > Sign-in method.
8. Aktifkan Anonymous.
9. Buka Realtime Database.
10. Create Database.
11. Buka Realtime Database > Rules.
12. Paste isi firebase.rules.json.
13. Klik Publish.
14. Upload ulang config.js ke GitHub.
